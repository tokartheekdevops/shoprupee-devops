Rolling Update

New Pods are introduced gradually while old Pods are replaced, reducing downtime during deployment.

OLD POD → NEW POD
🚧

Taint

Worker 1 is protected using a taint so that unrelated Pods are prevented from scheduling there.

WORKER 1 ⊣ UNMATCHED POD
🎟️

Toleration

ShopRupee declares a matching toleration allowing it to run on the tainted Worker 1.

TAINT ↔ TOLERATION
🎯

NodeSelector

NodeSelector selects the Kubernetes node having the matching label: dedicated=nginx.

dedicated=nginx → WORKER 1
