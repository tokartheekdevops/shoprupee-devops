📊 Prometheus & Grafana Monitoring

Monitoring and visualization added to the ShopRupee Kubernetes DevOps project.

🔭 Kubernetes Observability

Prometheus collects Kubernetes metrics and Grafana uses Prometheus as its data source to visualize pod health, replicas, restarts, CPU, memory and workload status.

P

Prometheus

Metrics collection and time-series monitoring system.

  • 🔎 Collects Kubernetes metrics
  • 📈 Stores time-series data
  • 🧮 Supports PromQL
  • ☸ Monitors pods and workloads
  • 🚨 Foundation for monitoring alerts
G

Grafana

Visualization layer connected to Prometheus.

  • 📊 Dashboard panels
  • 🟢 Deployment health
  • 🔄 Pod restart visibility
  • ⚙ CPU and memory charts
  • 📋 Tables and status panels
